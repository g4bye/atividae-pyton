
# Calculadora de Média Escolar

## Sobre o projeto

Este projeto foi desenvolvido em Python como atividade prática de programação.

O programa calcula a média de um aluno utilizando duas notas e informa se ele foi aprovado ou reprovado.

## Funcionalidades

- Solicitar o nome do aluno.
- Receber duas notas.
- Calcular a média automaticamente.
- Mostrar o resultado final.
- Informar se o aluno foi aprovado ou reprovado.

## Tecnologias utilizadas

- Python 3.

## Como executar

1. Ter o Python instalado no computador.
2. Baixar o arquivo script.py.
3. Abrir o terminal na pasta do projeto.
4. Executar o comando:

python script.py

## Exemplo de funcionamento

Aluno: Gabrielly
Primeira nota: 8
Segunda nota: 7
Média: 7.5
Situação: Aprovado!
